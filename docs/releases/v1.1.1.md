## 简体中文

U60Pro-OpenUI 1.1.1 是修复版。

- **配置文件里的 DNS 设置**：下载的配置文件如果把 DNS 服务器指向它自己的 DNS 监听端口（例如
  `127.0.0.1:7874`），这些条目现在会被去掉，改用正常的解析器。此前这类配置会让核心程序的外部连接全部失败。
- **诊断里的时钟**：B31 固件的系统时钟固定比网络时间快 8 小时（存的是北京时间），核心程序会用 NTP
  校正自己的时钟。诊断不再把这种情况报为警告，而是注明是北京时间。

1.1 的新功能（双指按住打开 DevUI、开机自动打开、闲置后熄屏）见
[v1.1 的发布说明](https://github.com/acloudpeng/U60Pro-OpenUI/releases/tag/v1.1)。

更新方法见 README 的「安装和更新」：在 Windows 上同步仓库后，双击 `deploy-windows.cmd`。
屏幕程序这次也有更新，部署后会自动运行约三分钟的触摸屏检查，期间请不要碰设备。
发布页附带的桌面安装器来自上游 OpenUI，会覆盖本项目的内容，请不要使用。

1.0 和 1.1 列出的真机验证项仍未完成。

## 繁體中文

U60Pro-OpenUI 1.1.1 是修正版。

- **設定檔裡的 DNS 設定**：下載的設定檔如果把 DNS 伺服器指向它自己的 DNS 監聽連接埠（例如
  `127.0.0.1:7874`），這些項目現在會被移除，改用一般的解析器。此前這類設定會讓核心程式的對外連線全部失敗。
- **診斷裡的時鐘**：B31 韌體的系統時鐘固定比網路時間快 8 小時（存的是北京時間），核心程式會用 NTP
  校正自己的時鐘。診斷不再把這種情況列為警告，而是註明是北京時間。

1.1 的新功能（雙指按住開啟 DevUI、開機自動開啟、閒置後關閉螢幕）請見
[v1.1 的發行說明](https://github.com/acloudpeng/U60Pro-OpenUI/releases/tag/v1.1)。

更新方法請見 README 的「安裝和更新」：在 Windows 上同步儲存庫後，按兩下 `deploy-windows.cmd`。
螢幕程式這次也有更新，部署後會自動執行約三分鐘的觸控螢幕檢查，期間請勿碰觸裝置。
發行頁附帶的桌面安裝程式來自上游 OpenUI，會覆蓋本專案的內容，請勿使用。

1.0 和 1.1 列出的實機驗證項目仍未完成。

## English

U60Pro-OpenUI 1.1.1 is a bug-fix release.

- **DNS settings in downloaded profiles**: DNS servers that point at the profile's own DNS listener
  (for example `127.0.0.1:7874`) are now dropped, and those names resolve with the normal resolver.
  Such a profile previously made every outside connection of the core program fail.
- **Clock in the diagnostics**: on B31 firmware the system clock runs 8 hours ahead of network time
  (it holds Beijing time), and the core program corrects its own clock with NTP. Diagnostics no longer
  report this as a warning; they say it is Beijing time.

For what 1.1 added (two-finger hold to open DevUI, opening at startup, screen off when idle), see the
[v1.1 release notes](https://github.com/acloudpeng/U60Pro-OpenUI/releases/tag/v1.1).

See "Install and update" in the README: on Windows, update your checkout and double-click
`deploy-windows.cmd`. The touchscreen program changed in this release too, so the update ends with
a touchscreen check of about three minutes; do not touch the device meanwhile. The desktop
installers attached here come from upstream OpenUI and would overwrite this project's additions; do
not use them.

The real-device checks listed for 1.0 and 1.1 are still open.
