## 简体中文

U60Pro-OpenUI 1.1 改进了在设备上打开触摸屏面板（DevUI）的方式，不用再反复按电源键。

- **双指按住打开 DevUI**（默认开启）：原厂界面亮着时，用两根手指按住屏幕不动 2 秒。
  - 单指长按、滑动、三根手指都不会打开，熄屏时按住也不会。
  - 原厂界面同时会收到这两根手指，请按在没有按钮的地方。
- **开机自动打开 DevUI**（默认关闭）：开机后等原厂界面启动完成再打开，关机充电时不会打开。
- **闲置后熄屏，留在 DevUI**（默认）：到了闲置时间只关屏幕，短按电源键唤醒。也可以改回返回原厂界面。
- **连按四次电源键**保留为可选方式，默认关闭。
- 这些都在网页控制台的「DevUI」页设置：「打开 DevUI 的方式」和「显示偏好」。

原厂锁屏挡不住双指按住和连按四次：锁屏时这样操作，同样会打开 DevUI。

更新方法见 README 的「安装和更新」：在 Windows 上同步仓库后，双击 `deploy-windows.cmd`。
这次屏幕程序有更新，部署后会自动运行约三分钟的触摸屏检查，期间请不要碰设备。
发布页附带的桌面安装器来自上游 OpenUI，会覆盖本项目的内容，请不要使用。

以下还没有在真机上验证过：
- 双指按住时原厂界面是否正常；
- 开机自动打开；
- DevUI 熄屏后长时间停留。

1.0 列出的 eSIM 和 Windows 一键更新的真机验证也还没有完成。

## 繁體中文

U60Pro-OpenUI 1.1 改進了在裝置上開啟觸控螢幕面板（DevUI）的方式，不必再反覆按電源鍵。

- **雙指按住開啟 DevUI**（預設開啟）：原廠介面亮著時，用兩根手指按住螢幕不動 2 秒。
  - 單指長按、滑動、三根手指都不會開啟，螢幕關閉時按住也不會。
  - 原廠介面同時會收到這兩根手指，請按在沒有按鈕的地方。
- **開機自動開啟 DevUI**（預設關閉）：開機後等原廠介面啟動完成再開啟，關機充電時不會開啟。
- **閒置後關閉螢幕，留在 DevUI**（預設）：到了閒置時間只關閉螢幕，短按電源鍵喚醒。也可以改回返回原廠介面。
- **連按四次電源鍵**保留為可選方式，預設關閉。
- 這些都在網頁控制台的「DevUI」頁設定：「打开 DevUI 的方式」（Ways to open DevUI）和「显示偏好」（Display preferences）。

原廠鎖定畫面擋不住雙指按住和連按四次：鎖定時這樣操作，同樣會開啟 DevUI。

更新方法請見 README 的「安裝和更新」：在 Windows 上同步儲存庫後，按兩下 `deploy-windows.cmd`。
這次螢幕程式有更新，部署後會自動執行約三分鐘的觸控螢幕檢查，期間請勿碰觸裝置。
發行頁附帶的桌面安裝程式來自上游 OpenUI，會覆蓋本專案的內容，請勿使用。

以下尚未在實機上驗證：
- 雙指按住時原廠介面是否正常；
- 開機自動開啟；
- DevUI 關閉螢幕後長時間停留。

1.0 列出的 eSIM 和 Windows 一鍵更新的實機驗證也尚未完成。

## English

U60Pro-OpenUI 1.1 changes how the touchscreen panel (DevUI) opens on the device, so it no longer
depends on repeated power-button presses.

- **Hold two fingers to open DevUI** (on by default): on the lit stock UI, hold two fingers still on
  the screen for 2 seconds.
  - A one-finger long press, a swipe or a third finger does not open it, nor does a hold on a dark
    screen.
  - The stock UI also receives both fingers, so place them where it has no button.
- **Open DevUI at startup** (off by default): DevUI opens once the stock UI has finished starting,
  never while the device charges switched off.
- **Turn the screen off and stay in DevUI when idle** (default): after the idle time only the screen
  turns off, and a short power press wakes it. Returning to the stock UI is still available.
- **Press four times to open DevUI** remains an option, off by default.
- All of these are on the dashboard's DevUI page, under "Ways to open DevUI" and "Display
  preferences".

The stock lock screen does not stop the two-finger hold or the four presses: either opens DevUI from
the lock screen too.

See "Install and update" in the README: on Windows, update your checkout and double-click
`deploy-windows.cmd`. The touchscreen program changed in this release, so the update ends with a
touchscreen check of about three minutes; do not touch the device meanwhile. The desktop installers
attached here come from upstream OpenUI and would overwrite this project's additions; do not use them.

Not yet verified on a real device:
- the two-finger hold together with the stock UI;
- opening at startup;
- long stays in DevUI with the screen off.

The real-device checks listed for 1.0, for eSIM and the Windows one-click update, are still open.
