## 简体中文

U60Pro-OpenUI 1.1.2 新增 **Wi-Fi 中继**：设备连上已有的 Wi-Fi（家里、酒店、办公室）作为上网通道，自己的热点照常工作，省下蜂窝流量。

- **网页「网络 → Wi-Fi 中继」**：扫描附近网络，选中后输入密码即可连接。可以保存多个网络，按列表顺序优先连接，也可以添加隐藏网络。
  状态卡显示当前流量走 Wi-Fi 还是蜂窝，以及信号、地址、流量和已联网时长。
- **自动切换**：上游 Wi-Fi 能上网时，所有流量都走它；断开、离开范围或上不了网时自动回到蜂窝网络，恢复后再切回。
  联网检查直接访问公共 DNS 的 IP 地址，不依赖域名解析。
- **网页认证**：酒店、机场这类要先在网页上登录的 Wi-Fi，会显示「需要网页认证」。开启 10 分钟的认证模式后，
  用连着本热点的手机或电脑打开登录页登录即可，登录一次所有设备都能用。
- **触摸屏**：新增「Wi-Fi 中继」页面，可以查看状态、开关中继、开始认证；概览页有一行入口，也可以在菜单里添加。
  网络和密码在网页上管理。
- **安全**：上游网络无法访问本设备和局域网。中继只使用运行时设置，不修改固件配置，关闭中继或重启后不留痕迹。

需要知道的：

- 中继需要设备固件自带 `wpa_supplicant`，**还没有在真机上验证过**。如果设备上没有，页面会显示「本设备没有 wpa_supplicant」。
- 热点和中继共用一块无线芯片，连上上游后热点可能切换到上游的信道，已连接的设备会断开几秒。
- 只支持 IPv4；中继生效期间，局域网设备的 IPv6 转发会暂停。

更新方法见 README 的「安装和更新」：在 Windows 上同步仓库后，双击 `deploy-windows.cmd`。
屏幕程序这次也有更新，部署后会自动运行约三分钟的触摸屏检查，期间请不要碰设备。
发布页附带的桌面安装器来自上游 OpenUI，会覆盖本项目的内容，请不要使用。

1.0 和 1.1 列出的真机验证项仍未完成。

## 繁體中文

U60Pro-OpenUI 1.1.2 新增 **Wi-Fi 中繼**：裝置連上既有的 Wi-Fi（家裡、飯店、辦公室）作為上網通道，自己的熱點照常運作，省下行動數據。

- **網頁「網路 → Wi-Fi 中繼」**：掃描附近網路，選取後輸入密碼即可連線。可以儲存多個網路，依清單順序優先連線，也可以新增隱藏網路。
  狀態卡顯示目前流量走 Wi-Fi 還是行動網路，以及訊號、位址、流量和已連線時間。
- **自動切換**：上游 Wi-Fi 能上網時，所有流量都走它；斷線、離開範圍或無法上網時自動回到行動網路，恢復後再切回。
  連線檢查直接存取公共 DNS 的 IP 位址，不依賴網域名稱解析。
- **網頁認證**：飯店、機場這類要先在網頁上登入的 Wi-Fi，會顯示「需要網頁認證」。開啟 10 分鐘的認證模式後，
  用連著本熱點的手機或電腦開啟登入頁登入即可，登入一次所有裝置都能用。
- **觸控螢幕**：新增「Wi-Fi 中繼」頁面，可以查看狀態、開關中繼、開始認證；概覽頁有一列入口，也可以在選單中加入。
  網路和密碼在網頁上管理。
- **安全**：上游網路無法存取本裝置和區域網路。中繼只使用執行期設定，不修改韌體設定，關閉中繼或重新開機後不留痕跡。

需要知道的：

- 中繼需要裝置韌體內建 `wpa_supplicant`，**尚未在實機上驗證**。如果裝置上沒有，頁面會顯示「本裝置沒有 wpa_supplicant」。
- 熱點和中繼共用一顆無線晶片，連上上游後熱點可能切換到上游的頻道，已連線的裝置會中斷幾秒。
- 只支援 IPv4；中繼生效期間，區域網路裝置的 IPv6 轉送會暫停。

更新方法請見 README 的「安裝和更新」：在 Windows 上同步儲存庫後，按兩下 `deploy-windows.cmd`。
螢幕程式這次也有更新，部署後會自動執行約三分鐘的觸控螢幕檢查，期間請勿碰觸裝置。
發行頁附帶的桌面安裝程式來自上游 OpenUI，會覆蓋本專案的內容，請勿使用。

1.0 和 1.1 列出的實機驗證項目仍未完成。

## English

U60Pro-OpenUI 1.1.2 adds a **Wi-Fi relay**: the device joins an existing Wi-Fi network (home, hotel,
office) and uses it as its internet connection while its own hotspot keeps running, saving mobile data.

- **Web page, Network → Wi-Fi relay**: scan for nearby networks, pick one and enter its password.
  Several networks can be saved and are tried in list order; hidden networks can be added. The status
  card shows whether traffic is on Wi-Fi or cellular, with signal, address, traffic and time online.
- **Automatic switching**: while the upstream Wi-Fi reaches the internet, all traffic goes over it.
  When it drops, goes out of range or has no internet, traffic returns to the cellular connection and
  switches back once it recovers. The online check contacts public DNS services by IP address, so it
  does not depend on name resolution.
- **Web login**: networks that want a sign-in page first (hotels, airports) show "Needs a web login".
  Start the ten-minute login mode, then sign in from a phone or computer on the hotspot; one sign-in
  covers every device.
- **Touchscreen**: a new Wi-Fi relay page shows the state, turns the relay on and off and starts the
  login mode; it has a row on Overview and can be added to the menu. Networks and passwords are
  managed on the web page.
- **Safety**: nothing on the upstream network can reach the device or the LAN. The relay uses runtime
  settings only and changes no firmware configuration; nothing is left once it is off or after a
  restart.

Good to know:

- The relay needs the `wpa_supplicant` that the firmware ships, and it **has not been tried on a
  device yet**. Without it, the page says the device has no wpa_supplicant.
- The hotspot and the relay share one radio, so joining a network may move the hotspot to that
  network's channel; its devices reconnect after a few seconds.
- IPv4 only; IPv6 forwarding for LAN devices is held while the relay carries traffic.

See "Install and update" in the README: on Windows, update your checkout and double-click
`deploy-windows.cmd`. The touchscreen program changed in this release too, so the update ends with
a touchscreen check of about three minutes; do not touch the device meanwhile. The desktop
installers attached here come from upstream OpenUI and would overwrite this project's additions; do
not use them.

The real-device checks listed for 1.0 and 1.1 are still open.
