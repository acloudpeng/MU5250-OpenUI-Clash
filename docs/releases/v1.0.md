## 简体中文

U60Pro-OpenUI 1.0 是第一个公开版本，适用于 CN B31 固件的中兴 U60 Pro（MU5250）。

- **网页控制台**：信号和频段、Wi-Fi 和路由器设置、客户端、APN、短信、流量、电池、日志和系统信息。界面有简体中文和英文。
- **eSIM**：管理卡槽里可插拔 eUICC 卡（9eSIM、5ber、eSTK.me 等）上的配置文件。
  - 网页上：切换、重命名、删除，用激活码或二维码下载，处理通知。
  - 触摸屏上：切换。
  - 基于 lpac v2.3.0：静态构建，带 9 个补丁。
- **触摸屏面板（DevUI）**：设备屏幕上的中英文菜单，包括电池与系统概览和 eSIM 页。
- **一键更新**：在 Windows 上双击 `deploy-windows.cmd`。它会：
  - 下载并校验本版本的文件；
  - 先试运行，确认后再部署；
  - 保留原有的密码和 PIN，跳过设备上已有的组件。

  部署失败时，会自动恢复原来的安装。

更新方法见 README 的「安装和更新」。发布页附带的桌面安装器来自上游 OpenUI，会覆盖本项目的内容，请不要使用。

以下还没有在真机上验证过：
- eSIM 读卡和切换，包括固件能否不重启就认出新的配置文件；
- 从真实的 SM-DP+ 下载配置文件；
- Windows 一键更新在真实电脑和设备上的完整运行。

插着普通 SIM 卡时，「蜂窝 → eSIM」里的 **读取卡片** 应该显示这是普通 SIM 卡。

## 繁體中文

U60Pro-OpenUI 1.0 是第一個公開版本，適用於 CN B31 韌體的中興 U60 Pro（MU5250）。

- **網頁控制台**：訊號和頻段、Wi-Fi 和路由器設定、用戶端、APN、簡訊、流量、電池、記錄檔和系統資訊。介面有簡體中文和英文。
- **eSIM**：管理卡槽中可插拔 eUICC 卡（9eSIM、5ber、eSTK.me 等）上的設定檔。
  - 網頁上：切換、重新命名、刪除，用啟用碼或 QR 碼下載，處理通知。
  - 觸控螢幕上：切換。
  - 基於 lpac v2.3.0：靜態建置，附 9 個修補。
- **觸控螢幕面板（DevUI）**：裝置螢幕上的中英文選單，包括電池與系統概覽和 eSIM 頁。
- **一鍵更新**：在 Windows 上按兩下 `deploy-windows.cmd`。它會：
  - 下載並校驗本版本的檔案；
  - 先試執行，確認後再部署；
  - 保留原有的密碼和 PIN，略過裝置上已有的元件。

  部署失敗時，會自動還原原來的安裝。

更新方法請見 README 的「安裝和更新」。發行頁附帶的桌面安裝程式來自上游 OpenUI，會覆蓋本專案的內容，請勿使用。

以下尚未在實機上驗證：
- eSIM 讀卡和切換，包括韌體能否不重新開機就認出新的設定檔；
- 從真實的 SM-DP+ 下載設定檔；
- Windows 一鍵更新在真實電腦和裝置上的完整執行。

插著一般 SIM 卡時，「蜂窝 → eSIM」（Modem → eSIM）裡的 **读取卡片**（Read the card）應顯示這是一般 SIM 卡。

## English

U60Pro-OpenUI 1.0 is the first public release, for the ZTE U60 Pro (MU5250) on CN B31 firmware.

- **Dashboard**: signal and bands, Wi-Fi and router settings, clients, APN, SMS, data usage, battery,
  logs and system information, in Simplified Chinese and English.
- **eSIM**: manage the profiles on a removable eUICC card (9eSIM, 5ber, eSTK.me and similar).
  - On the web page: switch, rename and delete profiles, download them from an activation code or
    QR image, and handle notifications.
  - On the touchscreen: switch profiles.
  - Uses lpac v2.3.0, a static build with nine patches.
- **Touchscreen panel (DevUI)**: a Chinese or English menu on the device's screen, with the battery
  and system overview and an eSIM page.
- **One-click update**: on Windows, double-click `deploy-windows.cmd`. It does the following:
  - downloads and checks this release's files;
  - runs a dry run, then deploys once you agree;
  - keeps the password and PIN, and leaves out components the modem already has.

  If a step fails, the previous installation is restored.

See "Install and update" in the README. The desktop installers attached here come from upstream
OpenUI and would overwrite this project's additions; do not use them.

Not yet verified on a real device:
- reading and switching eSIM profiles, including whether the firmware picks up a new profile
  without a restart;
- downloads from real SM-DP+ servers;
- a full one-click update from a real Windows PC to a real modem.

With an ordinary SIM in the tray, **Read the card** on Modem → eSIM should report an ordinary SIM.
