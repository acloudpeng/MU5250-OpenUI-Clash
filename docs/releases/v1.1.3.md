## 简体中文

U60Pro-OpenUI 1.1.3 带来触摸屏九宫格工具箱、网页状态条，并降低了触摸屏开着时的系统占用。

- **触摸屏工具箱**：菜单最多可放 9 个页面，5 个以上时排成九宫格。新增五个页面：
  - Wi-Fi：2.4 GHz、5 GHz 频段开关，网络名称和在线设备数；
  - 5G 信号：RSRP、SINR、频段、实时速率，网络制式切换（5G 自动、仅 5G SA、5G NSA、仅 4G）；
  - USB 与 TTL：USB 模式（RNDIS、NCM、ECM），TTL 关闭或 64、65、128；
  - 电池与充电：电压、电流、健康度，允许或暂停充电，充电上限 70%、80%、90% 或不限；
  - 加速清理：CPU、内存，停止可选的厂商进程，释放内存缓存。

  网页「DevUI」页可以一键选用九宫格预设或经典四行预设。
- **网页**：每个页面顶部有状态条（信号、网速、电量、CPU 与内存）；首页新增快捷工具箱（网络制式、TTL、充电上限、清理）。
  登录页标题改为「高级后台」。
- **更省资源**：
  - 触摸屏开着时，工具箱数据只在菜单里有工具箱页面时才读取，并且读法更轻；
  - 页面内容没有变化时，触摸屏不再重新排版和绘制。

  实测：触摸屏开着、默认菜单时，每分钟调用的系统命令与 1.1.2 相同（22 次），工具箱菜单为 42 次；
  大多数页面两分钟内只绘制 1–2 次，原来每 2 秒一次。
- **修复**：在触摸屏上切换网络制式后，立即显示新的制式。

工具箱各开关还没有在真机上逐一验证；切换 USB 模式时 USB 连接会断开几秒。

更新方法见 README 的「安装和更新」：在 Windows 上同步仓库后，双击 `deploy-windows.cmd`。
屏幕程序这次也有更新，部署后会自动运行约三分钟的触摸屏检查，期间请不要碰设备。
发布页附带的桌面安装器来自上游 OpenUI，会覆盖本项目的内容，请不要使用。

## 繁體中文

U60Pro-OpenUI 1.1.3 帶來觸控螢幕九宮格工具箱、網頁狀態列，並降低觸控螢幕開啟時的系統負載。

- **觸控螢幕工具箱**：選單最多可放 9 個頁面，5 個以上時排成九宮格。新增五個頁面：
  - Wi-Fi：2.4 GHz、5 GHz 頻段開關，網路名稱和線上裝置數；
  - 5G 訊號：RSRP、SINR、頻段、即時速率，網路模式切換（5G 自動、僅 5G SA、5G NSA、僅 4G）；
  - USB 與 TTL：USB 模式（RNDIS、NCM、ECM），TTL 關閉或 64、65、128；
  - 電池與充電：電壓、電流、健康度，允許或暫停充電，充電上限 70%、80%、90% 或不限；
  - 加速清理：CPU、記憶體，停止可選的廠商程序，釋放記憶體快取。

  網頁「DevUI」頁可以一鍵套用九宮格預設或經典四列預設。
- **網頁**：每個頁面頂部有狀態列（訊號、網速、電量、CPU 與記憶體）；首頁新增快捷工具箱（網路模式、TTL、充電上限、清理）。
  登入頁標題改為「高级后台」（簡體中文介面）／「Advanced admin」（英文介面）。
- **更省資源**：
  - 觸控螢幕開啟時，工具箱資料只在選單裡有工具箱頁面時才讀取，而且讀法更輕；
  - 頁面內容沒有變化時，觸控螢幕不再重新排版和繪製。

  實測：觸控螢幕開啟、預設選單時，每分鐘呼叫的系統指令與 1.1.2 相同（22 次），工具箱選單為 42 次；
  大多數頁面兩分鐘內只繪製 1–2 次，原本每 2 秒一次。
- **修正**：在觸控螢幕上切換網路模式後，立即顯示新的模式。

工具箱各開關尚未在實機上逐一驗證；切換 USB 模式時 USB 連線會中斷幾秒。

更新方法請見 README 的「安裝和更新」：在 Windows 上同步儲存庫後，按兩下 `deploy-windows.cmd`。
螢幕程式這次也有更新，部署後會自動執行約三分鐘的觸控螢幕檢查，期間請勿碰觸裝置。
發行頁附帶的桌面安裝程式來自上游 OpenUI，會覆蓋本專案的內容，請勿使用。

## English

U60Pro-OpenUI 1.1.3 adds a 3×3 toolbox on the touchscreen and a status bar on the web page, and
uses less of the system while the touchscreen is on.

- **Touchscreen toolbox**: the menu holds up to nine pages, shown as a 3×3 grid from five on. Five new
  pages:
  - Wi-Fi: 2.4 GHz and 5 GHz on/off, the network name and connected devices;
  - 5G signal: RSRP, SINR, band, live speed, and the network mode (5G auto, 5G SA only, 5G NSA,
    4G only);
  - USB & TTL: USB mode (RNDIS, NCM, ECM), TTL off or 64, 65, 128;
  - Battery & charge: voltage, current and health, allow or pause charging, a charge limit of 70, 80
    or 90 % or none;
  - Booster: CPU and memory, stop the optional vendor processes, drop the kernel caches.

  The DevUI page on the web offers a toolbox preset and a classic four-row preset.
- **Web page**: a status bar on every page (signal, speed, battery, CPU and memory) and a quick toolbox
  on Home (network mode, TTL, charge limit, cleanup). The sign-in page now reads "Advanced admin"
  ("高级后台" in Chinese).
- **Lighter on the system**:
  - with the touchscreen on, the toolbox data is read only while a toolbox page is in the menu, and
    more cheaply;
  - the touchscreen no longer lays out and draws a page whose content has not changed.

  Measured: with the touchscreen on and the default menu, system commands per minute are the same as
  in 1.1.2 (22), 42 with the toolbox menu; most pages are drawn once or twice in two minutes instead of
  every two seconds.
- **Fix**: after switching the network mode on the touchscreen, the new mode shows at once.

The toolbox switches have not each been tried on a device yet; switching the USB mode drops the USB
link for a few seconds.

See "Install and update" in the README: on Windows, update your checkout and double-click
`deploy-windows.cmd`. The touchscreen program changed in this release too, so the update ends with
a touchscreen check of about three minutes; do not touch the device meanwhile. The desktop
installers attached here come from upstream OpenUI and would overwrite this project's additions; do
not use them.
